Selamat datang di WebForge OS

Distro web server ringan yang dibangun dari Linux From Scratch 13.1 dengan systemd. Kelola situs, SSL, firewall, log, dan backup lewat satu perintah: webforge.

Jelajahi perintah Mulai cepat
root@webforge:/#

Yang sudah terpasang

Dasar sistem tetap kecil. Hanya komponen yang dibutuhkan web server.

Nginx web server nftables firewall OpenSSH akses jarak jauh acme.sh sertifikat Let's Encrypt systemd layanan dan timer apk manajer paket logrotate rotasi log

Perintah webforge

Cari perintah atau pilih kelompoknya. Klik "Salin" untuk menyalin perintah.

Paket dengan apk

WebForge OS memakai apk sebagai manajer paket. Berikut contoh pemakaian yang paling sering dipakai. Jalankan sebagai root atau lewat sudo.

Perbarui sistem

apk update

Segarkan indeks paket dari repositori. Jalankan ini dulu sebelum memasang atau upgrade.

apk upgrade

Naikkan semua paket terpasang ke versi terbaru.

apk list -u

Lihat paket yang punya versi lebih baru.

Pasang dan hapus

apk add nginx

Pasang satu paket. Beberapa paket sekaligus: apk add curl nano.

apk add nginx=<versi>

Pasang versi tertentu. Isi <versi> sesuai hasil apk policy.

apk add ./paket.apk

Pasang berkas .apk lokal, misalnya paket buatan sendiri.

apk del nginx

Hapus paket. Konfigurasi di /etc bisa tetap ada.

Cari dan lihat paket

apk search nginx

Cari paket berdasarkan nama.

apk search -v 'php*'

Cari dengan pola dan tampilkan versi.

apk policy nginx

Lihat versi yang tersedia dan dari repositori mana.

Periksa yang terpasang

apk info

Daftar semua paket yang terpasang.

apk info -L nginx

Daftar berkas yang dibawa paket nginx.

apk info -W /usr/sbin/nginx

Cari tahu paket mana yang memiliki berkas ini.

Perawatan

apk fix

Perbaiki paket yang rusak atau pemasangan yang terputus.

apk verify nginx

Cek keutuhan berkas paket.

apk cache clean

Bersihkan cache paket untuk menghemat disk.

Pemasangan sementara

apk add --virtual .build-deps gcc make

Pasang alat build sebagai satu grup bernama .build-deps.

apk del .build-deps

Hapus seluruh grup itu sekaligus setelah selesai build.

Opsi melewati pengecekan tanda tangan paket, jadi apk menerima paket yang tidak ditandatangani. Pakai hanya untuk repositori atau paket buatan sendiri yang Anda percaya.

Daftar repositori ada di /etc/apk/repositories. Untuk cek versi paket baru dari perintah WebForge, pakai webforge update-check.

Mulai cepat

Urutan awal setelah WebForge OS pertama kali menyala. Ganti contoh.id dengan domain Anda.

  1. Atur hostname, admin, dan situs pertama

    webforge setup

  2. Tambahkan situs

    webforge site add contoh.id

  3. Minta sertifikat HTTPS

    webforge ssl issue contoh.id

  4. Periksa kondisi server

    webforge health
